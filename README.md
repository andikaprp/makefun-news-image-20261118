One Day on Earth — the whole of Wednesday 18 November 2026 on a single page. 45 complete stories, each pinned where it happened on a midnight-observatory map and told in the order the sun reached them: 11 dispatches told in full with illustrated panels, 34 one-line briefs in a three-leg logbook (first light, midday, dusk), a six-number stat band, and a cutting-room box naming the stories held back on date discipline — Tuesday's events are never dressed up as Wednesday's, and Thursday's are marked not yet. The program is deterministic and offline: it reads stories-18.json and land.json and writes /output/entry.png.
